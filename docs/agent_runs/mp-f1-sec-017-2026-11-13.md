## 3. Findings Log

### Root Cause
The scanner's Passwords/Password assignment pattern on scan-secrets.sh line 36 was:
```
(password|passwd|pwd)[[:space:]]*[:=][[:space:]]*["'"][^"'[:space:]]{4,}
```
It matched the bare identifier `password`/`passwd`/`pwd` anywhere, including inside enum member names such as `EMPTY_PASSWORD`, causing a false positive on `credential.domain.ts`.

### Fix Applied
- `.kilo/scripts/scan-secrets.sh` line 36 changed to:
  ```
  (^|[^[:alnum:]_])(password|passwd|pwd)[[:space:]]*[:=][[:space:]]*["'"][^"'[:space:]]{4,}
  ```
- Added a `(^|[^[:alnum:]_])` lookbehind so the token must be preceded by a non-alphanumeric boundary (or start of line), excluding it from within identifiers.
