Workspace-level `kilo.jsonc` (including `plugin` array) is NOT read, even when present in the cwd. This prevents plugin discovery and dependency install entirely. It is unclear whether this is a CLI limitation or requires VS Code extension integration to set workspace context.
2. **Read-only npm cache persists:** `~/.npm/` and `~/.npm/_cacache/` are read-only at runtime (EROFS) despite `"sandbox": { "enabled": false }` in global config. The sandbox disable did not resolve the filesystem read-only restriction. This is an environmental blocker outside this task's scope.
3. **parent-watchdog shutdown:** kilo serve shuts down ~2s after start (`parent process gone`) because the launching shell exits. Server cannot be kept running long enough for HTTP endpoint probing or hook testing.
4. **No plugin-reporting endpoint:** `/diagnostics`, `/api/plugins`, `/api/health` were not probed (server dies too quickly), but previous SEC-013V run showed these endpoints do not report loaded plugins (`/diagnostics` 404, `/api/plugins` Not Found, `/api/health` returns only `{"healthy":true}`).
