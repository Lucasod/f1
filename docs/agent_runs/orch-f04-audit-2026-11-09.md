**2. File: `frontend/src/api/client.ts`**
- **withCredentials: true** — Ensures browser sends `sessionid` cookie with same-origin requests (per `playwright.config.ts` configuration)
- **CSRF Bootstrap**: `GET /auth/csrf/` extracts `csrf_token` from response body. This token is stored in memory and used for subsequent unsafe requests.
- **Token Rotation After Login**: The Django login view rotates the CSRF token. The `login()` function captures the new token from the response `X-CSRFToken` header and updates the stored token for subsequent requests.
- **`X-CSRFToken` Header Injection**: All `POST`, `PATCH`, `DELETE` requests must include `headers: { 'X-CSRFToken': csrfToken as string }`. The client automates this after `bootstrapCsrf()` or `login()` is called.
- **Error Envelope Parsing**: All API errors follow `{ error: { code, message, fields } }`. The `parseErrorEnvelope()` function extracts the meaningful message for user display, ignoring generic messages.
