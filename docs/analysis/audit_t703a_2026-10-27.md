## 2. Contrato de Imagens — `Product.images[]`

### 2.1 Uso no Domínio (`product.domain.ts:207-218`)
```typescript
addImage(imageUrl: string): void {
  if (!imageUrl || imageUrl.trim().length === 0) {
    throw new Error(ProductError.PRODUCT_IMAGE_URL_REQUIRED);
  }
  this.images = [...this.images, imageUrl];
  this.updatedAt = new Date();
}

removeImage(imageUrl: string): void {
  this.images = this.images.filter(img => img !== imageUrl);
  this.updatedAt = new Date();
}
```
- **Formato**: Array de strings (URLs completas)
- **Validação**: Apenas verifica se string não é vazia
- **Comportamento**: Adiciona/remove URLs diretamente

### 3.2 Magic Bytes — Verificação Detalhada
**JPEG**: `0xFF, 0xD8, 0xFF` — ✅ Correto  
**PNG**: `0x89, 0x50, 0x4E, 0x47, 0x0D, 0x0A, 0x1A, 0x0A` — ✅ Completo (8 bytes)  
**WebP**: RIFF (0-3) + size (4-7, variável) + WEBP (8-11) — ✅ Corrigido (CR-001)
- Loop pula bytes 4-7 (tamanho do arquivo) e valida RIFF + WEBP
- Testes: `createWebpBuffer()` gera buffer válido com assinatura completa

### 3.3 Path Traversal Prevention
| Local | Método | Status |
|-------|--------|--------|
| `LocalStorageAdapter.sanitizeKey()` | Regex `[^a-zA-Z0-9\-_\.\/]` + bloqueia `..` | ✅ |
| Serve endpoint | Usa `storageAdapter.sanitizeKey()` | ✅ (CR-002 corrigido) |
| Upload endpoint | Chave gerada server-side (não user-input) | ✅ |

**Teste de path traversal**: `GET /api/v1/uploads/../../../etc/passwd` → 400 `INVALID_KEY` ✅

### 3.4 Isolamento entre Vendors
- **Upload**: `vendorId` resolvido via `vendorRepo.findByPersonId(personId)` — apenas vendor autenticado
- **Ownership check**: `product.vendorId !== vendorId` → 403 `PRODUCT_OWNERSHIP_VIOLATION`
- **Admin bypass**: `isAdmin` permite acesso cruzado
- **Testes**: 
  - Vendor1 não acessa produto do Vendor2 (403) ✅
  - Admin acessa produto de qualquer vendor (201) ✅
  - Consumer não acessa (403) ✅

### 3.5 Autorização Admin
- **Middleware**: `requireVendorOrAdmin = requireRole(PersonRole.VENDOR, PersonRole.ADMIN)`
- **Verificação**: `req.user.roles.includes(PersonRole.ADMIN)` nas rotas

### 3.6 Entrega de Imagens por Chave
- **Endpoint**: `GET /api/v1/uploads/:key(*)` (público, sem auth)

- **Stream error handling**: `fileStream.on('error')` → 500 se headers não enviados (CR-007)
