## Root cause analysis

**Root cause 1 — Webhooks não entregues:** Stripe CLI não estava rodando (`stripe listen --forward-to`), então eventos `checkout.session.async_payment_succeeded` nunca chegavam ao backend. Ordens ficavam `PENDING_PAYMENT`, carrinhos nunca reconciliados, Vendor Dashboard mostrava zeros.

**Root cause 2 — TransferService falha bloqueava carrinho:** `createTransferWithDetails()` lançava exceção quando vendor não tinha Stripe connected account, fazendo o webhook retornar 500 antes da reconciliação do carrinho. Corrigido com try/catch — pagamento capturado é o core; transferência é side effect.
