### Fixes Applied

#### Fix 1: `clearAuth()` — Complete LocalStorage Clearance + CR-001 Hardening
**File:** `F01/front/tests/e2e/fixtures.ts` (lines 328-345)

**Changes:**
- Added removal of `refreshToken` and `user` localStorage keys
- Added handling for `about:blank` page (cannot access localStorage on about:blank)
- Added retry verification with descriptive error on failure (CR-001)

```typescript
// Before: Only cleared auth-storage and accessToken
await page.evaluate(() => {
  localStorage.removeItem('auth-storage');
  localStorage.removeItem('accessToken');
});

// After: Clears all 4 auth keys, handles about:blank, verifies with retry
await page.evaluate(() => {
  if (window.location.href === 'about:blank') return;
  localStorage.removeItem('auth-storage');
  localStorage.removeItem('accessToken');
  localStorage.removeItem('refreshToken');
  localStorage.removeItem('user');
});

// CR-001: Verify clearance with retry, throw descriptive error if failed
for (let attempt = 1; attempt <= 3; attempt++) {
  const remaining = await page.evaluate(() => {
    if (window.location.href === 'about:blank') return [];
    return ['auth-storage', 'accessToken', 'refreshToken', 'user'].filter(k => localStorage.getItem(k) !== null);
  });
  if (remaining.length === 0) break;
  if (attempt === 3) {
    throw new Error(`clearAuth() failed after 3 retries. Remaining keys: ${remaining.join(', ')}`);
  }
  await page.waitForTimeout(100);
}
```
